# Proyecto ZFNet + Agronomía (XAI con DeconvNet)

## Objetivo
Scaffold completo (modelo, backend, frontend, deploy) de ZFNet para clasificación agronómica con visualización DeconvNet, listo para recibir el tema/dataset definitivo.

## Estado
Descargando pesos e instalando dependencias para inspeccionar el grafo ONNX.

## Hecho
- Entorno relevado: Python 3.13.14, torch 2.15.0+cpu, node v24.15.0, npm 11.12.1 (usar `npm.cmd`), git 2.55.
- Pesos originales ImageNet: ONNX Model Zoo `onnxmodelzoo/zfnet512-12` (fp32 333 MB, int8 83 MB) descargados en `models/onnx/`.
- `configs/labels/imagenet_classes.txt` (1000 clases, orden synset) e imagen de prueba `scripts/samples/dog.jpg`.
- `scripts/inspect_onnx.py` para volcar nodos, atributos y formas.

## Pendiente
- Portar ZFNet a PyTorch verificando contra onnxruntime.
- DeconvNet, backend FastAPI, frontend Next.js, fine-tuning, docs.

## Decisiones
- Portar pesos a PyTorch (en vez de usar onnxruntime directo) porque el DeconvNet necesita los switches de max-pooling, que el grafo ONNX no expone.
- Deploy: Next.js en Vercel + FastAPI (Docker) en Hugging Face Spaces. PyTorch no entra en las funciones serverless de Vercel (límite 250 MB).

## Archivos tocados
- models/onnx/*.onnx, configs/labels/imagenet_classes.txt, scripts/inspect_onnx.py
